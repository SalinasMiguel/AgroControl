# Decisiones técnicas y de producto
Esta carpeta almacenará decisiones relevantes del proyecto (ADR o notas equivalentes).
Cada decisión importante deberá indicar:
1. contexto;
2. problema o decisión;
3. alternativas consideradas;
4. decisión tomada;
5. consecuencias conocidas.
En la Clase 01 todavía no se registra una decisión arquitectónica formal porque aún no se ha
iniciado el diseño técnico detallado.
